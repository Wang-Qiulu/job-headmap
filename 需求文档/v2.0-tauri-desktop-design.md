# v2.0 桌面化设计文档（Tauri 2 + macOS DMG）

> 写于 2026-06-09。取代 `打包.md`（原 Electron 方案，已弃用）。

---

## 1. 背景与目标

**问题**：现在数据 100% 存在浏览器 `localStorage`（key = `job-dashboard:v1`），清缓存、换浏览器、隐私模式都会丢。用户在用的过程中**一直心慌**，这是用户主诉。

**真正的解法**：把数据存到本地硬盘上一个看得见的 JSON 文件，让用户在 Finder 里能找到它、能复制、能 iCloud/坚果云同步、能放心。**导入/导出是补救手段，不解决问题——v2.0 不做**。

**目标用户**：自己用 + 程序员朋友 + GitHub 圈子。**不付 Apple Developer $99/年**，README 写清"右键 → 打开"即可。

**v2.0 范围**：
- ✅ Tauri 2.x 打 macOS DMG
- ✅ 数据存到 `~/Library/Application Support/com.jobheadmap.app/data.json`
- ✅ 每次写入自动备份，保留最近 7 份
- ✅ 原子写（`.tmp` + `fsync` + `rename`）防损坏
- ❌ 不做 localStorage 历史数据迁移（用户决定从零开始）
- ❌ 不做 JSON 导入/导出
- ❌ 不做 PWA、不打 Windows/Linux、不上 GitHub Actions
- ❌ 不做代码签名/公证

## 2. 为什么选 Tauri 而不是 Electron

| 维度 | Electron（原计划） | **Tauri 2.x（采用）** |
|---|---|---|
| DMG 体积 | ~100 MB | **~3-4 MB** |
| 内存占用 | 250-400 MB | **120-160 MB** |
| 启动时间 | ~3s 冷启动 | **~1-1.5s 冷启动** |
| WebView | 捆绑 Chromium | 系统 WKWebView |
| 跟 Zustand persist 适配 | 同步 IPC 麻烦 | invoke 天然异步 |
| 朋友愿意下载概率 | 100MB 国内劝退 | 4MB 一秒下完 |

Tauri 本身**不收费**。不付 $99 = 用户首次"右键 → 打开"，**第二次起正常**。

## 5. 关键技术决策

### 5.1 不用 `@tauri-apps/plugin-store`，自己写 Rust commands

**理由**：plugin-store 是 KV 字典语义，**没有原子写、没有备份轮转、没有自定义路径**。自己写 50 行 Rust 完全可控。

暴露 3 个 command：
```rust
#[tauri::command] async fn load_data(app: AppHandle) -> Result<Option<String>, String>;
#[tauri::command] async fn save_data(app: AppHandle, json: String) -> Result<(), String>;
#[tauri::command] async fn data_dir(app: AppHandle) -> Result<String, String>;
```

错误类型用 `String`：永远 `Serialize`，前端 `try/catch` 拿到人话。

### 5.2 存储路径

使用 Tauri 的 `app.path().app_data_dir()`，macOS 上解析为：

```
~/Library/Application Support/com.jobheadmap.app/
    ├── data.json
    └── backups/data-{YYYYMMDD-HHMMSS}.json  (最多 7 份)
```

**不硬编码 `JobHeadmap` 字符串**，直接用 identifier 自动生成路径，未来改 productName 不用追代码。

### 5.3 原子写 + 备份轮转

`save_data` 五步：
1. 写到 `data.json.tmp`
2. `f.sync_all()`（fsync，断电不丢）
3. `fs::rename(tmp, data.json)`（POSIX 原子）
4. `fs::copy(data.json, backups/data-{ts}.json)`
5. 列 `backups/` 按 mtime 排序，删超过 7 份

**用 `std::fs` 不用 `tokio::fs`**：Tauri command 跑在 tokio runtime 上，但 std::fs 阻塞调用会被 Tauri 内部 blocking pool 派发；写几百 KB JSON < 1ms，UI 完全无感。

`chrono` 用 `default-features = false, features = ["clock", "std"]` 控编译体积。

### 5.4 Zustand persist 异步 storage 适配

新建 `src/lib/persistStorage.ts`：

```ts
import type { StateStorage } from 'zustand/middleware'

const isTauri = () =>
  typeof window !== 'undefined' && '__TAURI_INTERNALS__' in window

// 浏览器 fallback（npm run dev:web 开发用）
const lsStorage: StateStorage = {
  getItem: (n) => localStorage.getItem(n),
  setItem: (n, v) => localStorage.setItem(n, v),
  removeItem: (n) => localStorage.removeItem(n),
}

// Tauri 实现（动态 import，避免 dev:web 找不到模块）
const tauriStorage: StateStorage = {
  async getItem(_) {
    const { invoke } = await import('@tauri-apps/api/core')
    const v = await invoke<string | null>('load_data')
    return v ?? null
  },
  async setItem(_, value) {
    const { invoke } = await import('@tauri-apps/api/core')
    await invoke('save_data', { json: value })
  },
  async removeItem(_) {
    const { invoke } = await import('@tauri-apps/api/core')
    await invoke('save_data', { json: '' })
  },
}

export const createAppStorage = (): StateStorage =>
  isTauri() ? tauriStorage : lsStorage
```

`useStore.ts` 改一行：
```ts
storage: createJSONStorage(() => createAppStorage())
```

**关键点**：
- 动态 `import('@tauri-apps/api/core')`：让 `npm run dev:web` 在浏览器里跑时不会因为找不到 Tauri runtime 而崩
- 首次启动 `load_data` 返回 `null` → Zustand 自动走初始值 → 触发 `buildSampleData()` → **零迁移代码就实现"从零开始"**
- `hasHydrated` 标志已经在 store 里，rehydrate 之前的写入 persist 会自动排队

### 5.5 tauri.conf.json 关键配置

```json
{
  "$schema": "https://schema.tauri.app/config/2.0.0",
  "productName": "JobHeadmap",
  "version": "0.1.0",
  "identifier": "com.jobheadmap.app",
  "build": {
    "beforeDevCommand": "npm run dev:web",
    "devUrl": "http://localhost:5173",
    "beforeBuildCommand": "npm run build:web",
    "frontendDist": "../dist"
  },
  "app": {
    "windows": [{
      "title": "求职面板",
      "width": 1280, "height": 800,
      "minWidth": 900, "minHeight": 600
    }],
    "security": {
      "csp": "default-src 'self'; img-src 'self' asset: data: https:; style-src 'self' 'unsafe-inline' https://fonts.googleapis.com; font-src 'self' https://fonts.gstatic.com data:; connect-src 'self' ipc: http://ipc.localhost https://fonts.googleapis.com https://fonts.gstatic.com"
    }
  },
  "bundle": {
    "active": true,
    "targets": ["dmg"],
    "icon": ["icons/32x32.png", "icons/128x128.png", "icons/128x128@2x.png", "icons/icon.icns", "icons/icon.ico"],
    "category": "Productivity",
    "macOS": { "minimumSystemVersion": "10.15" }
  }
}
```

**关键点**：
- `identifier` = `com.jobheadmap.app`（**不要用 `com.tauri.*` 或 `com.example.*`**）
- `targets: ["dmg"]` 不带 `"app"`：DMG 已经包含 .app，多打一份浪费时间
- CSP 必须包含 `connect-src 'self' ipc: http://ipc.localhost`，**漏了 `invoke` 全部 silent fail**

### 5.6 Vite 配置三处必改

```ts
export default defineConfig({
  plugins: [react()],
  base: './',                          // ← Tauri webview 用相对路径加载 assets
  resolve: { alias: { '@': path.resolve(__dirname, './src') } },
  server: {
    port: 5173,
    open: false,                       // ← 别让 Tauri dev 时弹两次窗
    strictPort: true,                  // ← 5173 被占要立刻 fail，不要静默
  },
})
```

### 5.7 package.json scripts 调整

```json
{
  "scripts": {
    "dev": "tauri dev",          // 默认 dev = Tauri（带 webview）
    "dev:web": "vite",           // 纯浏览器 HMR，日常 90% 时间用这个
    "build": "tauri build",      // 打 DMG
    "build:web": "tsc -b && vite build",  // 只构建前端（tauri build 内部调用）
    "preview": "vite preview",
    "lint": "tsc --noEmit",
    "tauri": "tauri"
  }
}
```

**开发节奏**：
- 改 UI / 组件 → `npm run dev:web`（Vite HMR 快）
- 改 Rust / 验证 storage → `npm run dev`（Tauri dev，启动慢但能跑真实路径）
- 提交前 → `npm run dev` 至少跑一次确认 webview 没问题

## 6. macOS 不签名发布的现实

### 用户第一次打开

1. 双击 DMG → 拖 `JobHeadmap.app` 到 Applications
2. 在 Applications 里 **右键 → 打开** → 弹窗点"打开"
3. 之后双击直接进

**不能用纯双击**——Sequoia 15.x 下未签名 .app 双击会被拦死，没有"取消 + 重试"的旧版逃生通道了。

### README 必须写的三句话

```markdown
## 安装

1. 下载 `JobHeadmap-x.x.x.dmg`
2. 双击挂载，**把图标拖到 Applications 文件夹**
3. 打开 Applications，**右键点 JobHeadmap → 打开** → 弹窗里再点"打开"
4. 之后双击就行了

> 如果系统说"已损坏，无法打开"，在终端跑：
> `xattr -dr com.apple.quarantine /Applications/JobHeadmap.app`
```

### Tauri 自动 ad-hoc 签名

`tauri.conf.json` 不设 `bundle.macOS.signingIdentity` 时，Tauri 2 默认对 .app **做 ad-hoc 签名**（无证书）——这正是"右键 → 打开"能用的根因。**不需要任何手动操作**。

## 7. 数据迁移（从零开始）

**用户决定**：不迁移 localStorage 旧数据。

**实现方式**：什么都不写。

**原理**：
- 首次 Tauri 启动 → `load_data` 找不到 `data.json` → 返回 `null`
- Zustand persist 拿到 `null` → 视为"没存过" → 走 `applications: []` 初始值
- `useStore.ts:73-94` 已有的 `hasHydrated + buildSampleData()` 逻辑触发 → 注入 6 条示例数据
- 用户从这里开始记录

**副作用**：用户原 localStorage 里的数据（如果有真实数据）**不会**自动出现在 Tauri App 里。如果用户哪天想要回，可以手动在 Chrome DevTools 里 copy `localStorage['job-dashboard:v1']` 的值，然后用任何文本编辑器贴到 `~/Library/Application Support/com.jobheadmap.app/data.json`。**不在 v2.0 范围**。

## 12. 风险与回退

| 风险 | 触发 | 回退 |
|---|---|---|
| 异步 storage 让 hydrate 闪烁 | rehydrate 慢 → 首屏空 | `hasHydrated` 已有 loading 态，无影响 |
| Tauri build 卡住 / 失败 | Rust 编译问题 | 仍可 `npm run dev:web` 当 web 用，零损失 |
| DMG 在 Sequoia 拦得太死 | macOS 改策略 | README 加 `xattr -dr` 兜底命令 |
| 用户清掉 Application Support | 误删 | backups/ 不会被一起删，手动改名恢复 |
| Tauri 升级 breaking | 未来事 | tauri.conf.json schema 锁版本 |

**关键回退**：v2.0 出任何问题，**rollback git** 即可——所有改动都在 Tauri 相关文件 + persistStorage.ts，业务代码零改动。
