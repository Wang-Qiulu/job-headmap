# Job Dashboard

## 一、产品简介

本地求职管理工具，帮助用户记录、管理和分析求职过程。

核心功能：GitHub风格热力图展示投递/面试活跃度 + 看板管理流程。

本地存储，无需登录、无需服务器。

---

## 二、目标用户

求职者。

---

## 三、产品目标

帮助用户回答：
1. 最近是否保持持续投递？
2. 总共投递了多少岗位？
3. 哪些岗位正在推进？
4. 当前面试和Offer情况如何？

## 四、产品结构

单页应用，包含：
- 求职热力图（支持投递/面试切换）
- 数据统计卡片
- 岗位列表表格
- 岗位详情抽屉

## 五、核心功能

### 5.1 求职活跃度热力图

GitHub风格展示，最近3个月（前月/当月/后月）。

布局：12列（周）× 7行（天）

**切换模式**：
- 投递模式：显示每天投递数量
- 面试模式：显示每天面试数量

**颜色级别**（0-4级，最深代表活跃度最高）：
- Level 0: 0次 (#ebedf0)
- Level 1: 1次 (#9be9a8)
- Level 2: 2-3次 (#40c463)
- Level 3: 4-5次 (#30a14e)
- Level 4: 6+次 (#216e39)

**Hover显示**：日期、数量（例：2026-03-15 · 3 Applications）

### 5.2 数据统计卡片

- 总投递：总投递岗位数
- 笔试：已完成笔试岗位数
- 一面：已一面岗位数
- 二面：已二面岗位数
- 三面：已三面岗位数
- Offer：Offer数

### 5.3 岗位管理

支持新增、编辑、删除岗位。

字段：
- 公司名称
- 岗位名称
- 投递日期
- 当前状态
- 岗位链接（可选）
- 岗位详情（可选）
- 备注（可选）

### 5.4 岗位列表表格

表格式展示所有岗位，like Excel。

**表格列**：
- 公司名称
- 岗位名称
- 投递日期
- 当前状态（下拉菜单，可直接改）
- 操作（编辑、删除）

**排列**：默认按投递日期倒序（最新投递在上）

**筛选**：支持按状态筛选
- 状态选项：计划中、已投递、笔试、一面、二面、三面、Offer

### 5.5 岗位详情抽屉

点击岗位卡片打开，支持编辑内容。

显示：
- 公司名称（可编辑）
- 岗位名称（可编辑）
- 岗位链接（可编辑）
- 投递日期（可编辑）
- 当前状态（可编辑）
- 备注（可编辑）

## 六、交互流程

1. 新增岗位 → 自动生成投递记录
2. 热力图、统计卡片、列表表格自动更新
3. 在表格中直接改变状态（下拉菜单）或点击编辑打开详情
4. 状态变更时自动记录变更时间
5. 按状态筛选表格内容
6. 数据自动保存本地

## 七、数据存储

本地 localStorage 存储，无需服务器、数据库。刷新页面后数据保留。

## 八、UI风格

设计参考：GitHub、Linear、Vercel、Notion

风格要求：
- 极简、高信息密度
- 白底、浅灰边框
- 低饱和度、开发者工具风格
- 热力图尽可能还原 GitHub Contribution Graph
- 卡片圆角、轻阴影、清晰信息层级

## 九、非目标（第一版本不包含）

- 用户系统/账号登录
- 云同步/多人协作
- 自动抓取招聘网站
- 简历优化/AI面试
- Offer对比
- 消息提醒

## 十、MVP完成标准

用户能够：
1. 新增/编辑/删除岗位
2. 查看投递和面试热力图（支持切换）
3. 查看投递统计数据
4. 在表格中查看所有岗位（支持按状态筛选）
5. 直接在表格中改变岗位状态
6. 本地保存数据
